# 🎨 絵文字コレクション

Unicode順に並んだ絵文字をクリックしてコピーできるWebアプリケーション

## 機能

- 📋 絵文字をUnicode順に表示
- 📱 レスポンシブグリッドレイアウト
- 🖱️ クリックで絵文字をクリップボードにコピー
- 💬 コピー時のトースト通知

## デモ

GitHub Pagesで公開中: https://dyki-ogawa.github.io/emoji-collection/

## 使い方

お好きな絵文字をクリックするだけでクリップボードにコピーされます。

## 技術スタック

- HTML5
- CSS3 (Grid Layout)
- Vanilla JavaScript
- GitHub Pages
